# OpenBene 阶段工作汇报（截至 2026-03-31）

> 预计汇报时长：3–5 分钟

---

## 一、这段时间在做什么？

OpenBene 项目这一阶段的核心目标是：

> **让 iPhone 成为机器人的"空间采集端"**
> ——用手机 LiDAR 采集场景数据，通过无线传输发给电脑，最终用于 3D 重建与未来的定位导航。

---

## 二、做了哪些具体工作？

### 1. iOS 采集 App：从能跑到好用

- **修复编译**：修正了 PNG 导出 API、补全相机和局域网权限声明、把最低支持系统从 iOS 18 降到 iOS 16，确保 App 可以顺利装到真机上。
- **改造采集流程**：从"自动乱拍"改成"手动确认模式"——先准备、再采集、看结果，操作更可控。
- **加入实时画面预览**：之前 App 里只有占位符，现在换成了真实的 AR 摄像头画面，所见即所拍。
- **采集质量反馈**：增加了实时质量提示，采集完后会显示一份质量报告，告诉用户这次数据质不质量。

### 2. 无线传输链路：打通从手机到电脑的全流程

- **接收端自动发现**：iPhone 上增加了 Bonjour 自动发现功能，附近的电脑接收端会自动出现，不再需要手动输入 IP 地址。
- **会话管理**：每次采集都有明确的"开始/结束"信号，双端握手，数据不会混淆。
- **两种工作模式**：
  - **建图模式**：采集完整 RGB + 深度 + 位姿数据，会话结束后打包上传。
  - **定位模式**：实时发送当前帧，延迟更低，为后续实时定位打基础。
- **点云上传**：会话结束后，额外上传一份轻量融合点云（`fused_pointcloud.ply`），方便快速判断采集质量，不影响原有数据格式。

### 3. PC 接收端（Python）：更稳定，更好用

- 修复了多次连接断开的问题，现在可以稳定接收多轮会话。
- 每次会话独立存到单独的文件夹，不会覆盖。
- 提高了 WebSocket 消息大小上限，解决了点云数据传输中途断开的问题。
- 支持 Bonjour 广播，让 iPhone 能自动找到它。

### 4. 界面优化：做减法

反复简化了 App 主界面，去掉了多余的状态条、重复的模式切换按钮，让主操作区更突出，信息更清晰。

---

## 三、现在能做到什么？

**一套完整的闭环已经跑通：**

```
iPhone 采集（LiDAR + 摄像头）
    ↓  WiFi 局域网
PC 接收端（Python）
    ↓
保存到本地：images/ + depth/ + transforms.json + fused_pointcloud.ply
    ↓
输入 Nerfstudio → 训练 → 3D 重建 ✅
```

Mac 上已完成过一次完整的"采集 → 传输 → Nerfstudio 训练 → 渲染出图"验证。
