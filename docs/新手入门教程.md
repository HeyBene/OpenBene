# 🤖 OpenBene 新手入门教程

> 适合：第一次拿到 OpenBot，完全没有基础的新手  
> 目标：独立完成环境搭建，让小车动起来！

---

## 📦 第零步：你需要准备什么

在开始之前，请确认你手边有以下东西：

| 硬件 | 说明 |
|------|------|
| OpenBot 小车 | 已组装好，带 Arduino 控制板 |
| Android 手机 | Android 7.0 以上，有 USB OTG 功能 |
| USB 数据线 | 手机 USB 接口 → Arduino Nano 的线（通常是 MicroUSB 或 TypeC） |
| 电脑 | Windows / Mac / Linux 均可，需要联网 |
| WiFi 路由器 | 手机和电脑必须连接**同一个** WiFi |

> ⚠️ **关键条件**：手机和电脑必须在同一局域网（连同一个 WiFi）才能通信！

---

## 第一步：刷入 Arduino 固件 🔧

Arduino 是控制小车电机的"翻译官"。需要把我们的固件代码烧录进去。

### 1.1 安装 Arduino IDE

1. 打开浏览器，访问 [https://www.arduino.cc/en/software](https://www.arduino.cc/en/software)
2. 下载 **Arduino IDE 2.x**（推荐）并安装
3. 安装完成后打开 Arduino IDE

### 1.2 打开固件文件

1. 在电脑上找到项目根目录里的 `openbot.ino` 文件
2. 双击打开（Arduino IDE 会自动启动并加载）

### 1.3 选择正确的开发板

在 Arduino IDE 中：

1. 点击顶部菜单 **工具（Tools）**
2. 选择 **开发板（Board）** → **Arduino AVR Boards** → **Arduino Nano**
3. 点击 **工具（Tools）** → **处理器（Processor）** → 选 **ATmega328P (Old Bootloader)**  
   （如果烧录失败就换成 **ATmega328P**）

### 1.4 连接 Arduino 到电脑

1. 用 USB 数据线把 Arduino Nano 连接到电脑
2. 在 Arduino IDE 中：**工具（Tools）** → **端口（Port）** → 选择出现的 COM 口（如 `COM3`）
   - Windows 显示 `COM3` / `COM4` 等
   - Mac 显示 `/dev/cu.usbserial-xxx`

### 1.5 烧录固件

1. 点击左上角 **→（上传）** 按钮
2. 等待底部显示 **"上传成功（Upload complete）"**
3. ✅ 完成！Arduino 的蓝色灯会闪一下表示烧录成功

> ❓ **烧录失败？** 尝试更换端口，或者把"处理器"从 ATmega328P Old Bootloader 换成 ATmega328P

## 第二步：安装手机 App 📱

### 2.1 下载 APK

在项目文件夹里找到：

```
openbot-mobile-control/releases/openbot-mobile-control-v1.0.6-with-discovery.apk
```

把这个 APK 文件传到手机上（可以用 QQ、微信、数据线传输均可）。

### 2.2 安装 APK

1. 在手机上找到下载好的 APK 文件，点击安装
2. 如果提示"**不允许安装未知来源应用**"：
   - 进入手机 **设置 → 安全 → 未知来源**，允许安装
   - 或者系统会直接弹出提示，点"仍然安装"
3. 安装完成，打开 App

### 2.3 验证 App 安装正确

打开 App 后，检查屏幕显示内容：

**✅ 正确（版本 v1.0.6）：**
- 显示 `Server Address: ws://192.168.x.x:8765`
- 显示 `Waiting for PC...`
- 有手机的本地 IP 地址（数字形式）

**❌ 错误（旧版本）：**
- 有 `PC IP Address` 输入框
- 有 `Connection Settings` 字样

> 如果看到错误版本界面，请卸载重装，确保使用的是 `v1.0.6` 这个 APK 文件！

### 2.4 授予必要权限

首次打开 App 会弹出权限请求，请全部允许：
- ✅ 摄像头权限（视频流）
- ✅ 存储权限（如有）

## 第三步：连接手机与小车 🔌

### 3.1 用 USB 连接手机和 Arduino

1. 用数据线把手机的 USB 口连接到 Arduino 的 USB 口
2. 手机可能弹出提示：**"允许 USB 设备访问吗？"** → 点 **确定** / **允许**
3. 勾选"**默认使用此应用打开**"（防止每次都弹窗）

### 3.2 检查连接状态

App 界面上应该显示 USB 连接状态变为已连接（绿色或有更新的状态文字）。

> ⚠️ **注意**：小车的电池需要有电！电量不足时电机不动但 App 可能显示正常。

## 第四步：配置电脑 Python 环境 💻

### 4.1 安装 Python

如果电脑还没有 Python：

1. 访问 [https://www.python.org/downloads/](https://www.python.org/downloads/)
2. 下载 **Python 3.10 或以上版本**
3. 安装时 **必须勾选** "**Add Python to PATH**"（路径自动添加）
4. 安装完成

验证安装：打开命令提示符（CMD）或终端，输入：

```bash
python --version
```

应该显示 `Python 3.x.x`。

### 4.2 安装 OpenBene SDK

打开命令提示符（Windows 按 `Win + R`，输入 `cmd`，回车），然后：

```bash
# 进入 SDK 目录（替换为你实际的项目路径）
cd C:\Users\你的用户名\Desktop\OpenBene\openbene_sdk

# 安装 SDK
pip install -e .
```

等待安装完成，会显示 `Successfully installed openbene...`。

### 4.3 验证 SDK 安装

```bash
python -c "from openbene import OpenBene; print('✓ SDK 安装成功！')"
```

显示 `✓ SDK 安装成功！` 就 OK 了。

## 第五步：手机和电脑连接同一 WiFi 🌐

这一步非常重要，经常被新手忽略！

1. 手机连上家里/实验室的 WiFi（比如 `MyWiFi`）
2. 电脑也连上**同一个** WiFi（`MyWiFi`）
3. **不要一个用 WiFi，一个用有线网线！**（会在不同子网）

验证方法：在电脑 CMD 里运行：
```bash
ping 192.168.x.x
```
（把 IP 换成 App 界面显示的手机 IP），能 ping 通就对了。

## 第六步：第一次连接测试 🚀

现在一切准备就绪！

### 6.1 准备工作

1. ✅ 小车通电（电池有电）
2. ✅ 手机 App 已打开，显示 `Waiting for PC...`
3. ✅ USB 数据线连接手机和 Arduino
4. ✅ 手机和电脑在同一 WiFi

### 6.2 运行自动连接测试

在电脑上打开命令提示符，进入 `openbene_sdk` 目录：

```bash
cd C:\Users\你的用户名\Desktop\OpenBene\openbene_sdk
```

新建一个测试文件，或者直接在 Python 交互模式中测试：

```bash
python
```

进入 Python 后逐行输入：

```python
from openbene import OpenBene
import time

# 自动发现手机（不需要手动输入 IP）
bot = OpenBene.auto_connect()
print(f"✓ 已连接到: {bot.ip}")

# 让小车前进 2 秒
bot.forward(0.5)
time.sleep(2)

# 停止
bot.stop()
print("停止！")

# 断开连接
bot.disconnect()
```

### 6.3 预期结果

- 电脑终端显示 `✓ 已连接到: 192.168.x.x`
- 手机 App 界面状态变为 **已连接（Connected）**
- 小车电机转动 2 秒后停止

## 第七步：运行基础控制示例 🎮

连接成功后，可以运行项目自带的示例脚本。

### 方法 1：运行基础控制示例

```bash
cd C:\Users\你的用户名\Desktop\OpenBene\openbene_sdk\examples
python basic_control.py
```

小车会自动执行：前进 → 左转 → 右转 → 后退 → 停止。

### 方法 2：手动控制小车

```python
from openbene import OpenBene
import time

bot = OpenBene.auto_connect()

# 常用控制命令：
bot.forward(0.5)      # 前进（速度 0.0~1.0）
bot.backward(0.3)     # 后退
bot.turn_left(0.4)    # 左转
bot.turn_right(0.4)   # 右转
bot.stop()            # 停止

# 精确控制左右轮速度
bot.drive(0.5, 0.5)   # 两轮都前进
bot.drive(-0.3, 0.3)  # 左轮后退，右轮前进 = 原地左旋

bot.disconnect()
```

### 速度参数说明

| 值 | 含义 |
|----|------|
| `1.0` | 全速 |
| `0.5` | 半速（推荐新手使用） |
| `0.0` | 停止 |
| `-1.0` | 全速倒退 |

## ❓ 常见问题排查

### 问题 1：`auto_connect()` 一直等待，连不上

**原因**：手机和电脑不在同一 WiFi，或 App 没有打开。  
**解决**：
1. 检查手机和电脑是否连同一 WiFi
2. 确认 App 已打开并显示 `Waiting for PC...`
3. 关闭电脑防火墙临时测试（Windows：控制面板 → Windows Defender 防火墙 → 关闭）

### 问题 2：USB 连接了，但电机不转

**原因**：Arduino 固件未刷入，或电池没电。  
**解决**：
1. 重新按第一步刷新 Arduino 固件
2. 检查小车电池电量
3. App 界面检查 USB 连接状态

### 问题 3：App 安装提示"未知来源"

**解决**：手机设置 → 应用管理 → 特殊权限 → 安装未知应用 → 允许对应的文件管理器安装。

### 问题 4：`pip install -e .` 报错

**解决**：
```bash
# 确认 pip 是最新版
python -m pip install --upgrade pip
# 重新安装
pip install -e .
```

### 问题 5：`python` 命令不存在

**解决**：Python 安装时没有勾选"Add to PATH"。  
重新安装 Python，安装界面第一页勾选 **"Add Python 3.x to PATH"**。

### 问题 6：手机连 USB 后反复弹出权限请求

**解决**：勾选"记住我的选择"或"默认使用此应用"，然后确认允许。
